# Ent'Artes — Dance School Management Platform

A web application developed to support the management and organisation of a dance school.

This project was developed entirely by me using React, JavaScript and Vite, with the goal of creating a practical and user-friendly platform for managing different activities within a dance school.

## Features

- **Dashboard:** Overview of school activities and relevant information.
- **Coaching Management:** Interface for managing coaching sessions and requests.
- **Teacher Availability:** Management and organisation of teacher availability.
- **Session History:** Access to previous sessions and activity records.
- **Inventory Management:** Interface for organising and managing school inventory.
- **Request Validation:** Management and validation of submitted requests.
- **User Profiles:** Different interfaces for school management, teachers and parents/guardians.
- **Interactive Interface:** Navigation between pages and interactive elements.

## Technologies Used

- **React** — Building the application's user interface.
- **JavaScript** — Implementing functionality and interactivity.
- **HTML5** — Structuring web content.
- **CSS3** — Styling and page layouts.
- **Vite** — Development environment and build tool.

## Getting Started

To run the project locally, make sure you have Node.js and npm installed.

### 1. Clone the repository

```bash
git clone https://github.com/franciscoc20/EntArtes-Web.git
```

### 2. Open the project folder

```bash
cd EntArtes-Web
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal to access the application.
